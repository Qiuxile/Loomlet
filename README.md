# Loomlet

> 键盘流图形化脚本工作台。打开即写，把代码块织成脚本。

Loomlet 是一款面向脚本与小型项目的桌面开发环境。它打破了传统编辑器只能“逐行输入”的限制，将脚本结构转化为**画布上的代码框**。开发者可以在无限画布上自由组合逻辑，配合极速的键盘导航，体验全新的脚本编写方式。

---

## 设计理念

- **打开即工作台**：无需繁琐的项目创建与环境配置，启动即进入画布工作区，满足快速编写临时脚本的需求。
- **结构先于语法**：用小型的“框”来代表一个函数或执行单元。通过画布上的空间排布，直观呈现代码的调用关系与数据流向。
- **键盘驱动的心流**：全程无需频繁切换鼠标。采用层级化的模态导航，让双手在键盘上完成切框、选行、填参与执行。

---

## 核心特性

### 画布式代码组织
- 每一个**框**都是一个独立的代码单元。
- 当脚本只有一个框时，框内的代码可以直接执行。
- 当有多个框时，每个框代表一个命名函数，框之间可通过连线表达调用与数据传递。
- **主函数双圈标识**：画布中作为程序入口的主函数框，以特殊的双圈视觉样式进行高亮区分。

### 图形与代码双模式
- **图形模式**：以画布、框和连线的空间形态呈现逻辑架构。
- **代码模式**：以纯文本视图完整展示最终生成的源代码。
- 两种模式共享同一份底层数据，保存项目时，即可同步生成标准且可直接运行的 `.py` 文件，保证代码不被工具锁死。

### 模态化键盘导航
- 借鉴 Vim 的操作哲学，将画布划分为**框 -> 行 -> 参数**的层级结构。
- **导航态**：使用方向键或 `WASD` 在画布上的框之间快速移动；使用其他键位在框内的代码行之间切换。
- **编辑态**：按下空格或编辑键，即可进入当前行的代码编写模式；按 `Esc` 退回导航态。
- **参数流转**：支持快捷键（如 `Tab`）直接跳转至下一个框，并自动聚焦参数位置，实现代码编写的无缝衔接。

### 智能辅助与执行反馈
- **行内编辑**：在框内编辑代码时，提供精准的代码补全。
- **引用搜索**：支持快捷键唤出搜索弹窗，通过粗/细搜索快速查找并引用已有方法，大幅减少手打。
- **即时运行**：一键执行当前框或整个脚本。
- **精准定位**：若运行过程中发生异常，错误回溯信息将直接映射到画布上具体的框与代码行，并通过高亮直观反馈。

## 界面概念

| 概念         | 含义                                                         |
| :----------- | :----------------------------------------------------------- |
| **工作台**   | 打开软件即见的默认布局，包含画布、侧边栏与底部输出面板。     |
| **框**       | 画布上的最小代码容器，承载一段完整的代码逻辑。               |
| **主函数框** | 双圈标识的入口框，代表脚本运行的主程序（如 `if __name__ == "__main__"`）。 |
| **行**       | 框内的具体代码文本行，支持单行独立编辑。                     |
| **连线**     | 用于表达框与框之间调用关系的连接线。                         |

## 项目计划

- **当前阶段**：核心工作台构建，实现画布交互、代码框编辑与单框直接执行。
- **近期目标**：完成多框函数化映射、主函数入口标识，以及图形/代码双模式的实时同步。
- **进阶规划**：实现完整的模态化键盘导航体系，引入引用搜索与自动补全，提供异常回溯至画布框的精准定位。
